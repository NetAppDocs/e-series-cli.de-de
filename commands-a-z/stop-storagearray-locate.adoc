= Speicherarray-Lokalisierung stoppen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `stop storageArray locate` Mit dem Befehl werden die Kontrollleuchten auf dem Speicher-Array ausgeschaltet, das vom eingeschaltet wurde `start storageArray locate` Befehl.



== Unterstützte Arrays

Dieser Befehl gilt für jedes einzelne Speichersystem, einschließlich der E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 und EF80 Arrays, sofern alle SMcli Pakete installiert sind.



== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Storage-Array auszuführen, müssen Sie die Storage Admin-Rolle haben.



== Syntax

[source, cli]
----
stop storageArray locate
----


== Parameter

Keine.



== Minimale Firmware-Stufe

6.10
