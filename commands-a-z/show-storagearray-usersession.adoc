= Speicherarray-Benutzersitzung anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `show storageArray userSession` Mit dem Befehl können Sie den Zeitraum für das Sitzungszeitlimit von System Manager anzeigen.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für einzelne E4000, E2800, E5700, EF600, EF300, EF50 und EF80 Speicherarrays. Er funktioniert nicht auf E2700 oder E5600 Speicherarrays.



[[roles]]
== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Storage-Array auszuführen, müssen Sie die Rolle Storage Admin, Support Admin oder Storage Monitor haben.



[[parameters]]
== Parameter

Keine.



[[syntax]]
== Syntax

[source, cli]
----
show storageArray userSession
----
