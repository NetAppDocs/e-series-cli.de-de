= Host-I/O-Protokollinformationen des Storage-Arrays anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der  `show storageArray hostIoProtocolInformation` Befehl zeigt Informationen über die E/A-Protokolleinstellungen für ein bestimmtes Speicherarray an.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für jedes einzelne Speichersystem, einschließlich der E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 und EF80 Arrays, sofern alle SMcli Pakete installiert sind.



[[roles]]
== Rollen

Um diesen Befehl auf einem E4000-, E2800-, E5700-, EF600-, EF300-, EF50- oder EF80-Speicherarray auszuführen, müssen Sie die Support Admin-Rolle haben.



[[syntax]]
== Syntax

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== Parameter

Keine.



[[minimum-firmware-level]]
== Minimale Firmware-Stufe

12,00
