= Host-I/O-Protokollinformationen des Storage-Arrays anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der  `show storageArray hostIoProtocolInformation` Befehl zeigt Informationen über die E/A-Protokolleinstellungen für ein bestimmtes Speicherarray an.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für ein E4000, EF50 oder EF80 Speicherarray, sofern alle SMcli Pakete installiert sind.



[[roles]]
== Rollen

Um diesen Befehl auf einem E4000, EF50 oder EF80 Speicherarray auszuführen, muss die Rolle Support Admin vorhanden sein.



[[syntax]]
== Syntax

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== Parameter

Keine.



[[minimum-firmware-level]]
== Minimale Firmware-Stufe

12,00
