= Konfiguration des Überwachungsprotokolls anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `show auditLog configuration` Mit dem Befehl werden die Konfigurationseinstellungen für das Revisionsprotokoll für das Speicherarray angezeigt.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für einzelne E4000, E2800, E5700, EF600, EF300, EF50 und EF80 Speicherarrays. Er funktioniert nicht auf E2700 oder E5600 Speicherarrays.



[[roles]]
== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Storage-Array auszuführen, müssen Sie die Security Admin-Rolle haben.



[[syntax]]
== Syntax

[source, cli]
----
show auditLog configuration
----


[[parameters]]
== Parameter

Keine.



[[examples]]
== Beispiele

[listing]
----

SMcli -n Array1 -c "show auditLog configuration;"

Logging level: All
Full policy: Overwrite
Maximum records: 30,000 count
Warning threshold: 90 percent

SMcli completed successfully.
----
