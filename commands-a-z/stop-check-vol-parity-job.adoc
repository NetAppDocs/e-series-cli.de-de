= Stoppen Sie den Job zur Überprüfung der Volumeparität – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `stop check volume parity job` Befehl stoppt eine laufende Überprüfung des Volume-Paritätsjobs.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für jedes einzelne Speichersystem, einschließlich der EF600, EF300, EF50 und EF80 Systeme; sofern alle SMcli Pakete installiert sind.



[[roles]]
== Rollen

Um diesen Befehl auf einem EF600-, EF300-, EF50- und EF80-Speicherarray auszuführen, müssen Sie die Rolle Storage Admin haben.



[[syntax]]
== Syntax

[source, cli, subs="+macros"]
----
stop check volume parity job jobId=<job_id>;
----


[[parameters]]
== Parameter

|===
| Parameter | Beschreibung 


 a| 
`jobId`
 a| 
Die Job-id, die dem Check Volume Parity Job entspricht, um den Job zu stoppen. Dieser Wert ist erforderlich.

|===


[[minimum-firmware-level]]
== Minimale Firmware-Stufe

11.80
