= Einstellungen für die Zertifikatssperrprüfung anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `show storageArray revocationCheckSettings` Mit dem Befehl können Sie die Einstellungen für den Zertifikatsperrbefehl für das Speicher-Array anzeigen.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für einzelne E4000, E2800, E5700, EF600, EF300, EF50 und EF80 Speicherarrays. Er funktioniert nicht auf E2700 oder E5600 Speicherarrays.



[[roles]]
== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Storage-Array auszuführen, müssen Sie die Security Admin-Rolle haben.



[[parameters]]
== Parameter

Keine.



[[syntax]]
== Syntax

[source, cli]
----
show storageArray revocationCheckSettings
----


[[example]]
=== Beispiel

[listing]
----
SMcli -n Array1 c "show storageArray revocationCheckSettings;"
Revocation Checking: Disabled
OCSP Responder Server URL: https://ocspResponderURL.com
SMcli completed successfully.
----
