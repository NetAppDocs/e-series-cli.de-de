= Testen der E-Mail-Benachrichtigungskonfiguration – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `start emailAlert test` Mit dem Befehl können Sie die Warnungskonfiguration durch Senden einer Beispiel-E-Mail-Nachricht testen.



== Unterstützte Arrays

Dieser Befehl gilt für einzelne E4000, E2800, E5700, EF600, EF300, EF50 und EF80 Speicherarrays. Er funktioniert nicht auf E2700 oder E5600 Speicherarrays.



== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Speichersystem auszuführen, müssen Sie die Rolle Storage Admin oder Support Admin haben.



== Syntax

[source, cli]
----

start emailAlert test
----


== Parameter

Keine.



== Beispiele

[listing]
----

SMcli -n Array1 -c "start emailAlert test;"

The sample alert message was successfully sent to the email addresses.

SMcli completed successfully.
----


== Minimale Firmware-Stufe

8.40
