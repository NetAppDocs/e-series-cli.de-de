= Syslog-Konfiguration anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `show syslog summary` Mit dem Befehl werden die Konfigurationsinformationen für die Syslog-Warnmeldung angezeigt.



[[supported-arrays]]
== Unterstützte Arrays

Dieser Befehl gilt für einzelne E4000, E2800, E5700, EF600, EF300, EF50 und EF80 Speicherarrays. Er funktioniert nicht auf E2700 oder E5600 Speicherarrays.



[[roles]]
== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Storage-Array auszuführen, müssen Sie die Rolle Storage Admin, Support Admin oder Storage Monitor haben.



[[syntax]]
== Syntax

[source, cli]
----
show syslog summary
----


[[parameters]]
== Parameter

Keine.



[[examples]]
== Beispiele

[listing]
----

SYSLOG SUMMARY
   Default facility: 3
   Default tag: StorageArray
   Syslog format: rfc5424
   Syslog Servers
      Server Address               Port Number
      serverName1.company.com      514
      serverName2.company.com      514

SMcli completed successfully.
----


[[minimum-firmware-level]]
== Minimale Firmware-Stufe

8.40

11.70.1 fügte die hinzu `syslogFormat` Parameter zur Angabe des Syslog-Nachrichtenformats.
