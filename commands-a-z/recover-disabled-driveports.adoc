= Deaktivierte Laufwerksanschlüsse wiederherstellen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `recover disabled drivePorts` Befehl stellt deaktivierte Laufwerksports wieder her.



== Unterstützte Arrays

Dieser Befehl gilt für jedes einzelne Speichersystem, einschließlich der E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 und EF80 Arrays, sofern alle SMcli Pakete installiert sind.



== Rollen

Um diesen Befehl auf einem E2800, E5700, EF600, EF300, EF50 oder EF80 Speicherarray auszuführen, müssen Sie die Storage Admin Rolle haben.



== Syntax

[source, cli]
----
recover disabled drivePorts;
----


== Beispiele

[listing]
----
recover disabled drivePorts;
