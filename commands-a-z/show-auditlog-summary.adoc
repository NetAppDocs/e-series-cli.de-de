= Audit-Protokollzusammenfassung anzeigen – SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der `show auditLog summary` Befehl zeigt die Zusammenfassungsinformationen des Prüfprotokolls an.



== Unterstützte Arrays

Dieser Befehl gilt für einzelne E4000, E2800, E5700, EF600, EF300, EF50 und EF80 Speicherarrays. Er funktioniert nicht auf E2700 oder E5600 Speicherarrays.



== Rollen

Um diesen Befehl auf einem E4000, E2800, E5700, EF600, EF300, EF50 oder EF80 Storage-Array auszuführen, müssen Sie die Security Admin-Rolle haben.



== Syntax

[source, cli]
----
show auditLog summary
----


== Parameter

Keine.



== Beispiele

[listing]
----

SMcli -n Array1 -c "show auditLog summary;"

Total log records: 1,532
First log record: 1493070393313 (2017-04-24T16:46:33.313-0500)
Last log record: 1493134565128 (2017-04-25T10:36:05.128-0500)

SMcli completed successfully.
----
